# dragonfly-urma-tools

Standalone validation and benchmark tools for Dragonfly URMA adaptation.

## Tools

- [`urma-b7/`](./urma-b7/) — B7 real-provider validation harness for Dragonfly URMA, including environment discovery, isolated config generation, correctness runs, evidence collection, cleanup, and test cases.

The tools were moved out of `engineering-lab/dragonfly-urma-adaptation/tools` so test automation can evolve independently from the engineering notes.
